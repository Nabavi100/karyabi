# کارجوی هرات

نسخهٔ وب‌سایت کاریابی ولایت هرات با چند صفحه و منو.

## صفحات

- `index.html` — خانه و تازه‌ترین آگهی‌ها
- `agahi.html` — همه آگهی‌ها
- `categories.html` — دسته‌بندی‌ها
- `companies.html` — شرکت‌ها
- `post.html` — ثبت آگهی
- `cv.html` — رزومه
- `about.html` — درباره ما
- `contact.html` — تماس با ما
- `login.html` / `register.html` — ورود و ثبت‌نام

## اجرا

```bash
python3 -m http.server 8080
```
