# کارجوی هرات

اپ موبایل کاریابی ولایت هرات. داده در فایل `karjo-db.json` کنار برنامه ذخیره می‌شود.

## اجرا روی کامپیوتر (آفلاین)

۱. Python 3 را نصب کنید.  
۲. در ویندوز `start.bat` را باز کنید، یا در ترمینال:

```bash
python run-offline.py
```

- برنامه: http://127.0.0.1:8080  
- صفحهٔ مدیریت جدا: http://127.0.0.1:8080/admin.html  
- رمز مدیر: `nabavi`  
  (در برنامهٔ اصلی دکمهٔ ⋮ را ۷ ثانیه نگه دارید)

فایل را مستقیم با دابل‌کلیک روی `index.html` باز نکنید؛ JSON ذخیره نمی‌شود.

## ذخیرهٔ داده

هر تغییر مدیر روی `karjo-db.json` نوشته می‌شود. کپی پشتیبان خودکار: `karjo-db.json.bak`.
