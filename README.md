# کارجوی هرات

نسخهٔ وب‌سایت کاریابی ولایت هرات — بازسازی‌شده از [کارجوی هرات](https://nab-tools.neocities.org/Herat-Karjo/).

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا:

```bash
python3 -m http.server 8080
```

سپس به `http://localhost:8080` بروید.

## امکانات

- فهرست آگهی‌ها با تاریخ شمسی
- جستجو و فیلتر (دسته، نوع قرارداد، آگهی جدید)
- بنر تبلیغاتی
- ذخیرهٔ آگهی در مرورگر
- تماس، تلگرام و واتساپ کارفرما
