برنامه

ورود مدیر

این صفحه مال کاربران نیست. فقط برای ذخیره و به‌روز کردن فایل JSON برنامه است.

فایل JSON خوانده نشد

اگر فایل را مستقیم از پوشه باز کرده‌اید، برنامه را با python3 server.py اجرا کنید یا از دکمهٔ ورود JSON استفاده کنید.

مدیریت داده‌ها

هر ذخیره روی karjo-db.json نوشته می‌شود. برنامهٔ اصلی همان فایل را می‌خواند؛ بقیهٔ داده‌ها پاک نمی‌شوند.

راه‌های ارتباطی مدیر

شماره تماس، واتساپ و تلگرام. کاربران این فرم را نمی‌بینند.

لیست کارفرمایان / شرکت‌ها

افزودن یا ویرایش شرکت. آگهی‌ها سر جایشان می‌مانند.

آگهی‌های کار

افزودن، ویرایش یا حذف آگهی. بعد از ذخیره در برنامهٔ اصلی دیده می‌شود.

آدرس‌های مهم

شفاخانه، بانک، آموزشگاه، شرکت، رستوران و تکت‌فروشی.

تغییر رمز مدیر

همین رمز برای صفحهٔ مدیریت جدا و ورود مخفی داخل برنامه (نگه‌داشتن ⋮) استفاده می‌شود.

بکاپ JSON

دانلود کل فایل، یا ورود فایل بکاپ.
